# 圖片與歌詞自動編排 JSON

先在「歌詞編輯 → 素材」用「加入圖片／影片素材」上傳圖片，再到「JSON 圖片字幕編排」按「下載 JSON 範例」。範例包含 12 秒、5 個段落，使用「清晨.png」、「海岸.png」、「夜色.png」三個圖檔名稱；請先加入這些圖片，或將各段落的 `name` 改為已上傳的圖片檔名，再用「匯入圖片字幕 JSON」開啟。JSON 只記錄檔名、時間與字幕，不含圖片或 Base64 資料；歌曲音訊請另外匯入。

匯入會切換至手動時間軸，替換 V1 畫面片段與整份字幕，保留既有音訊片段、素材庫與樣式。請先加入歌曲音軌，再匯入 JSON，讓最後一張圖片貼齊歌曲結尾。新的片段可繼續編輯，也可儲存為 `.resonance` 專案或瀏覽器草稿。原有自動輪播功能維持原本行為；切回自動編排圖片仍會清空 V1。

```json
{
  "version": 1,
  "scenes": [
    {
      "name": "清晨.png",
      "startTime": 0,
      "endTime": 3,
      "content": "晨光輕輕落在窗前"
    },
    {
      "name": "清晨.png",
      "startTime": 3,
      "endTime": 6,
      "content": "我們迎著微風向前"
    },
    {
      "name": "海岸.png",
      "startTime": 6,
      "endTime": 10.5,
      "content": "讓心事隨海浪慢慢走遠"
    }
  ]
}
```

- `version`：固定為 `1`。
- `scenes`：1～500 個圖片段落，匯入後依開始時間排序。
- `name`：已匯入素材庫的唯一圖片檔名，例如 `清晨.png`（包含副檔名，大小寫須一致）。匯入時依此配對圖片，不支援圖片網址或本機路徑。
- `startTime`：字幕開始秒數，也是切換至該張圖片的時間（第一張圖片固定從 0 秒開始）。須為 0 以上的數字，例如 `0`、`3.5`。不要加引號。
- `endTime`：字幕結束秒數，須晚於 `startTime` 至少 0.05 秒。圖片會繼續顯示到下一段開始，不會在此時間消失。時間使用整首歌曲的絕對秒數，匯入時四捨五入至毫秒。
- `content`：歌詞文字。以 `\n` 分隔同時顯示的多行文字；空白行會略過。不同時間出現的歌詞請分成多個段落。

字幕仍從 `startTime` 顯示到 `endTime`；圖片則連續貼齊，不因字幕空檔而消失：第一張圖片從 0 秒顯示到第二段的 `startTime`，之後每張從自己的 `startTime` 顯示到下一段開始，最後一張延伸到現有音軌或最後一句字幕結束，以較晚者為準。只有一張圖片時會覆蓋整段作品。沒有音軌時，以最後一句字幕的 `endTime` 作為結尾。

同一張圖片可在多個段落重複使用，匯入時會共用圖片素材。切換依時間軸片段邊界進行；原有輪播間隔與轉場設定不套用於此匯入。貼齊依匯入當下的音軌長度計算，若之後加入歌曲或延長音軌，請重新匯入 JSON，或手動延長最後一個圖片片段。

每句字幕至少 0.05 秒，字幕之間與圖片段落之間不可重疊。JSON 檔案上限 64 MiB；先上傳圖片、再以 `name` 引用，可避免將圖片資料放入 JSON 而超過上限。程式會先驗證所有時間與圖片，全部成功後才套用；缺圖、重名、格式錯誤或圖片無法解碼時，保留原作品。成功匯入會重新開始畫面與字幕的編輯復原歷史。

舊版 `image` 欄位仍支援素材庫圖片檔名，或 `data:image/png;base64,...`、`data:image/jpeg;base64,...`、`data:image/webp;base64,...`。有提供 `image` 時會沿用它指定的圖片來源，`name` 維持選填顯示名稱；省略 `image` 時則以 `name` 配對素材庫。

先前以 `srt` 字串記錄字幕的 JSON 仍可匯入。新格式請使用 `startTime`、`endTime`、`content` 三個欄位；只填部分欄位會顯示錯誤，不會改用舊資料。
