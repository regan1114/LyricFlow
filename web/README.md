LyricFlow 的 Vue 3 影音編輯器，從 `video_visual` 整合而來。前端入口為 `index.html`，Flask 提供建置後的 `dist/`。本文件的 npm 指令在 `web/` 執行；專案根目錄也提供相同的轉接指令。

## 啟動

需要 Node.js 22.12 以上。建議使用 Node.js 22 LTS。

```sh
npm ci
npm run dev
```

開啟終端顯示的本機網址。開發模式需透過 Vite 啟動，不能直接雙擊 `index.html`。

```sh
npm run build
npm run preview
npm run lint
npm run typecheck
npm test
npm run test:e2e
```

正式版本輸出至 `dist/`。可在已啟動 Flask 的情況下驗證正式版本：

```sh
PLAYWRIGHT_BASE_URL=http://127.0.0.1:8765 npm run test:e2e
```

此模式不啟動 Vite，略過需要直接匯入 TypeScript 原始碼的引擎測試；一般 `npm run test:e2e` 仍包含這些測試。

端對端測試使用本機 Google Chrome，並自動啟動 5173 埠的 Vite；若已有本專案的伺服器則重用。

## Vercel：只部署 Vue 前端

靜態版保留素材匯入、播放、字幕編輯、手動對時、場景、影片匯出與瀏覽器草稿，關閉自動辨識入口及 Python API 呼叫。素材處理在瀏覽器執行，不需要部署 Python、辨識引擎或模型。

第一次在 Vercel 選擇 **Add New → Project**，連接已推送的 Git 倉庫，設定如下：

| 設定             | 值                     |
| ---------------- | ---------------------- |
| Root Directory   | `web`                  |
| Framework Preset | `Vite`                 |
| Install Command  | `npm ci`               |
| Build Command    | `npm run build:static` |
| Output Directory | `dist-static`          |

請選擇整合後的 `web`，不是原始備份 `video_visual`。`web/vercel.json` 已提供建置設定；不需要辨識服務網址、API Key 或額外環境變數。首次部署後，在 Vercel 專案的 Git 設定確認 Production Branch；推送到該分支會更新正式網站，其他分支／PR 則產生預覽部署。這使用 [Vercel 的 Git 整合](https://vercel.com/docs/git)，不需要另外新增 GitHub Actions 部署流程。Root Directory 的設定方式見 [Vercel 多專案文件](https://vercel.com/docs/monorepos)。

在 `web/` 或專案根目錄預覽與驗證相同的靜態版本：

```sh
npm run build:static
npm run preview:static
npm run test:static
```

`build:static` 使用 Vite 的 `static` mode，輸出至 `web/dist-static/`；一般 `npm run build` 仍輸出至 `web/dist/`，供本機 Flask 使用並保留辨識。兩者獨立，不會互相覆蓋。本機 `dev` 模式也保留辨識。草稿依網站來源分開儲存，本機、Vercel 預覽網址與正式網址不會自動共用；可下載 `.resonance` 專案後重新匯入。

## 程式分層

```text
src/
  App.vue                 組合畫面、提供單一工作區實例
  components/
    player/               預覽畫布、匯入工具列、播放控制
    settings/             連續捲動的設定面板與表單欄位
    lyrics/               歌詞編輯與逐句對時
    ui/                   按鈕與檔案選擇元件
  composables/            Vue 狀態、使用者操作與生命週期
  domain/                 不依賴 Vue 或 DOM 的字幕規則
  services/               檔案下載、Canvas 去背等瀏覽器操作
  engine/
    renderer.ts           依序執行各個繪製步驟
    frame.ts              各繪製步驟共用的強型別畫格
    animation.ts          幀率無關的位移、緩動與生成頻率
    particleTypes.ts      粒子與軌跡資料型別
    passes/               時間、背景、特效、光核、歌詞與資訊繪製
    scenes/               Three.js 場景合成、天文計算及各場景 GLSL
    textBitmap.ts         多語字幕量測、關鍵字與文字快取
    backgroundPainter.ts  圖片運鏡與影片影格快取
  config/                 設定定義、預設值、字型與選項
  styles/                 桌面與手機版樣式
tests/
  unit/                   字幕格式、時間精度、去背邊界
  e2e/                    瀏覽器操作、錄影、畫布與響應式驗證
```

元件只處理呈現與事件；播放、錄影、媒體載入與歌詞操作分別由 composable 負責。`createStudio()` 為每個應用實例建立狀態，以 `provide/inject` 提供給工作區元件，沒有跨實例的全域可變 store。

繪圖引擎不匯入 Vue。高頻動畫資料與 DOM／AudioContext 資源保留為普通物件，避免每個動畫影格觸發元件重繪。資源容器的 `current` 是引擎內的普通可變欄位，不是 React ref。`frame` 僅承載單次繪製共享的資料；持續動畫狀態存於 `renderState`。

設定的標籤、型別、範圍與預設值集中在 `config/settings.ts`。新增設定時，先定義欄位，再於所屬繪圖步驟實作；不要在元件加入 Canvas 演算法。字幕解析與序列化放在 `domain/subtitles.ts`，能獨立測試。

TypeScript 已啟用完整 `strict` 檢查，涵蓋應用與測試。`StudioSettings` 由設定欄位推導，`RenderFrame`、`RenderResources`、粒子與字幕使用明確型別；新增欄位需維持對應的資料契約。正式打包前請執行 `npm run typecheck`。

素材庫與播放時間軸分離：作品時鐘由 AudioContext 驅動，多個音訊片段經同一混音節點送至頻譜分析、播放與錄影；來源 URL 不代表作品播放時間。背景匯入僅在成功提交時切換模式，過期載入不覆蓋新選擇。場景紋理失敗後會清除進行中快取，預覽以遞增間隔重試，最長間隔為 30 秒。

影片粒子的位移、淡出與生成率以 60 FPS 為基準換算實際時間；單幀補算最多 100 ms，避免背景分頁恢復時大量跳動。頻譜陣列及畫格容器重用。字圖快取採 LRU 與 32 MiB 像素預算，主題變色重用文字排版與畫布。

此分工採用 [Vue 官方 composables 的狀態與生命週期管理方式](https://vuejs.org/guide/reusability/composables)。事件監聽、動畫影格、Object URL、音訊節點與錄影串流均在所屬模組負責清理。

## 功能與相容性

- 本機音訊播放、暫停、音量、進度與低頻取樣。
- SIGNAL 即時頻譜、時域波形與圓環模式，可調整尺寸及垂直位置。
- 圖片／影片背景、順序／隨機輪播、依時間／歌詞換頁、影片速度與轉場。
- 五組內建沉浸場景：極光峽灣、北歐暖爐木屋、哈斯塔特湖畔、京都雨夜町屋與森林溪流木平台；可切回無場景或改用自訂背景。
- LRC／SRT 匯入、文字編輯、逐句對時、復原、插入空白時間點及字幕下載。
- 16:9、1:1、9:16 畫布；光球、流體、黑膠、頻譜及原有氛圍特效。
- Logo、光核媒體、疊圖、混合模式與色度去背。
- 畫布與音訊同步錄製；依瀏覽器能力輸出 MP4 或 WebM，副檔名與實際格式一致。

一般歌詞編輯使用浮動面板，仍可操作播放器；進入對時才開啟對話框。對時時可用空白鍵或右方向鍵標記、左方向鍵復原、`0` 插入空白、Enter 完成；也有對應按鈕。取消對時不會覆寫原歌詞。

影片背景與 Logo／光核影片為靜音素材，錄影音軌來自匯入的音訊。GIF 與 SVG 在 Canvas 中以靜態圖片處理，動態素材請使用影片。內建 11 款 OFL 繁體中文字型，字型檔與授權放在 `public/fonts/`；預覽與匯出共用同一字型。啟動時沒有背景圖片，也不會下載預設背景；可自行匯入圖片或影片。

沉浸場景素材放在 `public/scenes/`。哈斯塔特照片及其改作採 CC BY-SA 4.0，來源署名保留於 `hallstatt-attribution.txt`；其餘場景為生成的風格模擬影像。

場景特效由 Three.js 的獨立著色器合成，照片與遮罩共用 cover 座標，再合入 MV 畫布供預覽及錄影。極光為流動光幕；木屋雪限於窗玻璃、火焰限於爐膛；京都雨限於庭院；森林和湖畔水波依素材遮罩繪製。哈斯塔特日期、月相、自然日月軌跡由 Astronomy Engine 計算，月表使用 NASA 素材。

`sceneSettings` 與影片 `settings` 分開管理，場景動畫也有獨立時間。切換場景不會更動影片的雨雪、霧氣、調色等參數。影片氛圍特效仍可額外疊加；場景動畫開關不會暫停影片特效。場景素材按需載入，共用一個 GPU context，卸載時釋放資源。

桌面版控制介面使用半透明毛玻璃：滑鼠進入播放區時顯示，離開後以一秒淡出；歌詞對時期間保持顯示。鍵盤 Tab 也可開啟控制介面，觸控裝置與手機版則保持可操作。特效快捷列與設定面板共用同一份狀態。

錄影需要瀏覽器支援 MediaRecorder 與 Canvas captureStream，預設從作品起點錄製，也可在「匯出設定」指定開始與結束秒數。錄影期間鎖定設定和素材更換。專案與素材可手動下載保存。

錄影狀態分為準備、錄製、收尾及閒置。準備期間可取消；收尾完成前不允許再次啟動，以免遺失最後片段。錄影仍採記憶體暫存，累積至 256 MiB 時會停止並下載已錄製的部分，同時顯示提示；最後一個編碼片段可能讓輸出略超過門檻。這不是串流寫檔或無限制長片匯出。

## 字幕編輯整合

按「歌詞編輯」切換至左側 70% 預覽、右側 30% 字幕與底部時間軸。逐句字幕以「編號＋歌詞」呈現，支援直接編輯、貼上多行自動分句、搜尋取代及新增；手動對時直接使用逐句字幕，起訖時間在下方時間軸調整。時間軸支援拖移、左右裁切、分割、複製、刪除、復原／重做、吸附、軌道鎖定、縮放與水平捲動。變更即時同步預覽和 SRT 匯出；LRC 格式僅記錄開始時間。

快捷鍵（輸入欄位外）：Space 播放／暫停、S 分割、Delete 刪除、⌘／Ctrl+Z 復原、⌘／Ctrl+Shift+Z 重做、⌘／Ctrl+D 複製。按住 ⌘／Ctrl 滾輪可縮放時間軸。

字幕編輯操作移植自 `OpenCut-Studio/app/video-editor.tsx`，沿用現有 Vue 播放器與字幕渲染。OpenCut 授權保留於 `public/LICENSE-OPENCUT`。

## 多媒體素材與時間軸

Dashboard 的「畫面與背景 → 畫面編排」可切換兩種互斥模式，預設為自動編排圖片。自動編排只使用素材區中的圖片，可設定順序／隨機、依時間／歌詞換頁、間隔及轉場；影片不參與。自動模式會清空並鎖住 V1，素材、音軌和字幕保留，復原／重做也不會帶回已清除的 V1 片段。切回手動後 V1 解鎖，需重新加入圖片或影片。自動圖片啟用後即使用獨立計時持續循環，時間軸播放、暫停、跳轉與錄影開始都不會重設輪播。依歌詞模式重複使用字幕時間間距作為獨立換頁節奏；無有效字幕節奏時使用輪播間隔。自動圖片不建立或改變時間軸長度。

- 圖片／影片共用多選輸入，MP3／WAV 等音訊共用另一個多選輸入；首次匯入音訊會自動將第一首可用歌曲加入 A1 起點，保持滿版並可直接播放；同批其餘歌曲與後續匯入只追加素材庫，不改動已排好的片段。
- 右側「素材」頁可個別加入或全部依序加入。V1 為圖片／影片，A1 為主要音訊，音訊素材的「配音軌」按鈕可於播放頭位置加入 A2。音訊重疊時混音，V1 重疊時顯示開始時間較晚的片段。
- 圖片預設 5 秒，可自由延長；影片與音訊片段的來源起點加長度不能超過來源。片段支援拖移、兩側裁切、分割、複製、刪除和影音復原／重做。刪除片段保留素材；使用中的素材不能直接移除。
- 影片原音預設關閉，可逐片開啟並調整音量。作品長度取影音軌的最晚結束時間，字幕不延長影片。畫面軌空檔使用原本場景／視覺設定，音訊空檔保持靜音。
- SRT／LRC／TXT 為單份字幕文件，重新匯入會替換。移動影音預設不移動字幕；開啟「連動字幕」後，整段移動會連動原片段時間範圍內開始的字幕，裁切不改字幕。
- 編輯影音片段會暫停播放；錄影與手動對時期間停用影音修改。預覽和錄影使用相同時間軸、影片同步與混音。

## 專案保存、風格與匯出設定

右側特效快捷列下方提供獨立的「場景設定」面板，可收合、選擇沉浸場景並調整各場景專屬特效；手機版排列於特效快捷列與 Dashboard 之間。自動編排模式也會顯示此入口；選擇內建場景時切換至手動時間軸，保留已匯入素材。

左側 Dashboard 提供三個可展開區塊：

- **專案**：下載 `.resonance` 專案檔，包含素材庫中的原始音訊／圖片／影片、Logo／光核／疊圖素材、字幕、影音時間軸、場景與匯出設定。檔案沒有壓縮，容量接近所有素材的總和。內建場景使用應用內附素材；本機自訂字型仍需在開啟專案的電腦安裝。
- **風格預設**：內建抒情字幕、Lo-fi 暖夜、電子節奏，支援復原最近一次套用，以及最多 30 組具名收藏。風格包含畫面參數與場景設定；套用時保留歌曲資訊、字幕內容、畫布比例、Logo／疊圖設定和時間軸。自動圖片及手動時間軸素材仍優先顯示，場景在手動模式的畫面空檔呈現。收藏存於目前瀏覽器，不包含素材檔。
- **匯出設定**：原始畫布或短邊 720／1080 px（等比例縮小、不放大）、30／60 FPS、4／8／16 Mbps、自動／MP4／WebM，以及完整作品／指定秒數區段。預覽解析度不隨輸出尺寸改變。按播放器錄影鍵開始即時錄製；指定格式不支援時會提示，沒有靜默改用其他格式。

編輯後會自動儲存一份草稿到目前瀏覽器的 IndexedDB（同網址與連接埠）。「專案與草稿」可暫停、立即儲存、恢復或刪除；重整後先選擇恢復或以目前作品取代，不會自動覆寫既有草稿。草稿包含素材、字幕與設定；清除網站資料或重置會刪除草稿。重要作品請另按「儲存專案」下載 `.resonance` 備份。

開啟專案會替換目前作品，建議先下載要保留的版本。載入時先檢查檔案版本、設定、素材索引與片段範圍，成功解碼所有匯入素材後才提交；格式錯誤或素材無法解碼時保留原作品。開啟後播放頭回到起點，編輯復原歷史重新開始。

匯出面板會估算影片與音訊的容量，超過 256 MiB 時提示降低畫質或縮短區段。錄影仍採記憶體暫存，達上限會停止並下載已錄片段；目前沒有串流寫檔或離線逐幀匯出。實際位元率、幀率及區段邊界精度取決於瀏覽器與執行效能。

## 自動辨識

右上角「自動辨識」先檢查是否已匯入歌曲，接著開啟歌詞彈窗。多首歌曲可選擇來源；選用歌曲需已加入音軌。每行輸入一句實際演唱的歌詞後按「送出」。若已有字幕，會提示刪除並取代；按「取消」保留彈窗輸入，不送出工作。

辨識使用本機 LyricFlow 引擎，需先安裝模型並啟動 Flask。彈窗顯示目前階段進度，可取消辨識。成功後才取代字幕；失敗、沒有可套用結果或取消時保留原字幕。結果依所選歌曲各音軌片段的開始與裁切範圍換算，並顯示未定位／待檢查句數。可使用字幕復原回到取代前的內容。

Vite 開發模式會將 `/api` 轉接至 `http://127.0.0.1:8765`；正式版本與 API 共用 Flask 來源。辨識期間暫停字幕、素材與專案變更及錄影。

## 字幕拖曳框選

在字幕軌道的空白處（包含字幕上、下方留白）按住滑鼠左鍵拖曳，與選取框相交的字幕都會選中，向左或向右拖曳皆可。縮放後拖至左右邊緣會自動水平捲動。軌道標題顯示選取數量，點空白處清除選取，框選途中按 Escape 還原原本選取。

拖曳已選字幕可整批移動，保留相對間隔且不會超出時間零點。複製、刪除與對應快捷鍵套用到整批字幕，復原／重做以整批操作為單位。點單一字幕回到單選；拉動左右裁切把手只調整該句。多選時停用分割。鎖定、錄影、手動對時或自動辨識期間不啟動框選。

## 重置工作區

右上角「重置」經確認後清空目前作品與舊版字幕編輯暫存，再重新載入空白工作區，釋放目前頁面的媒體、字幕、復原歷史及預覽快取。錄影、辨識、手動對時或素材／專案載入期間停用重置。

重置不刪除電腦原始檔、已下載專案、收藏風格或後端辨識工作資料。重新載入後，畫面設定回到預設值。

## 效能與驗證

字幕多選使用集合查找並略過相同選取狀態的更新；影音播放每幀以單次掃描選擇有效畫面。自動辨識連線逾時會顯示錯誤，取消後不再套用結果。

從專案根目錄執行 `.venv/bin/python scripts/check.py --browser`，可在建置後一併驗證 Flask、Chrome 與前端單元測試。
